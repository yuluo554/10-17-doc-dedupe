# 02 · 架构与技术选型

- 版本：v1（2026-10-17，M0 计划期定稿）
- 上游：`plan/01-题目文档.md`（题目）、`data/README.md`（口径与数据纪律）
- 状态：M0 骨架期；本文档描述**目标架构**，未实现部分在 M1–M5 逐棒落地

## 一、总体形态

```
                 ┌──────────────────────────────┐
   文件系统 ───▶ │ ① 扫描与格式适配层            │
                 │  walk / extract / cache      │
                 └──────────────┬───────────────┘
                                │ 归一化正文 + 元数据
                 ┌──────────────▼───────────────┐
                 │ ② 指纹与召回层                │
                 │  normalize / shingle / hash  │
                 │  SimHash 分桶 + MinHash/LSH  │
                 └──────────────┬───────────────┘
                                │ 候选对 + 分数
                 ┌──────────────▼───────────────┐
                 │ ③ 聚类与保留建议层            │
                 │  union-find / 三档 / 理由     │
                 └───────┬──────────────┬───────┘
                         │              │
          ┌──────────────▼───┐   ┌──────▼────────────────┐
          │ ④ 复核界面        │   │ 报告导出               │
          │ FastAPI + 原生 JS │   │ md / csv / json        │
          └──────────┬───────┘   └───────────────────────┘
                     │ 用户显式确认
          ┌──────────▼───────────────────────────────┐
          │ ⑤ 安全执行与回滚层                        │
          │ quarantine/manifest 状态机 / undo / 报告  │
          └──────────────────────────────────────────┘
```

分层原则：

| 层 | 职责 | 禁止 |
|---|---|---|
| 引擎层（`scan`/`fingerprint`/`cluster`/`diff`） | 确定性计算与判定 | 不读时钟、不联网、不写用户文档 |
| 编排层（`pipeline`） | 串流程、合并退出码 | 不重算判定、不复制口径 |
| 表现层（CLI 输出 / Web 页面 / 报告渲染） | 只消费引擎结果 | 不做判定、不内联阈值 |

**唯一事实源**：数值口径只在 `data/README.md` §四 定义；运行时从 `src/docdedupe/config.py`
的默认配置对象读取（配置键与文档一一对应），其余任何位置不得出现第二份阈值字面量。

## 二、技术选型与弃选

| 关注点 | 选型 | 理由 | 弃选 |
|---|---|---|---|
| 语言/运行时 | Python，下限 3.8 | 本机 `py -0p` 实测仅 3.8.8 与 3.12；下限 3.8 让 CI 双解释器矩阵可覆盖老环境 | 3.9+ 新语法（会直接排除本机 3.8 通道） |
| PDF 文本层 | `pypdf` | 纯 Python、无系统库依赖、文本层抽取足够；比 pdfplumber 轻（pdfplumber 依赖 pdfminer.six + Pillow） | pdfplumber（重依赖、版面还原超出首期需要）；自研 PDF 解析（失败面大） |
| DOCX | `python-docx` | 段落 + 表格读取成熟；只读不写 | 自研 OOXML 解析（表结构与命名空间坑多） |
| Markdown/HTML/TXT | 标准库（`html.parser`、`re`） | 无额外依赖 | 第三方 markdown 渲染器（会把正文变成 HTML 噪声） |
| 指纹 | 自实现 SimHash + MinHash/LSH | 口径完全可控、零依赖、便于单测；`simhash`/`datasketch` 均非必需 | `simhash` 库（仅 64 位实现，无 LSH）；`datasketch`（引入 numpy 依赖） |
| 索引缓存 | SQLite（标准库 `sqlite3`） | 单文件、随包、无服务 | 外部数据库（违背纯本地轻量） |
| Web 服务 | FastAPI + uvicorn | 本地绑定 `127.0.0.1`，路由简单、自带 JSON 序列化 | Flask（同样可行但无类型化响应）；任何需要前端构建链的方案 |
| 前端 | 原生 HTML/CSS/JS 单页 | 零构建、零 CDN、断网可用 | React/Vue（引入构建链，违背交付形态） |
| 打包 | 源码包 + editable 安装（首期不做 exe） | 首期形态是 CLI + 本地 Web；exe 属扩展项 | PyInstaller（首期无需求，反而增加发布面） |

**依赖版本策略**：核心依赖写**上下界**，且每一侧都要有真实环境跑过（3.8 与 3.12 双解释器）。
可选依赖（如 Web 服务栈）走 extras，不在核心安装面；缺 extras 时命令必须 exit 3 并给出安装提示，
**不得静默降级成"零结果"**。

## 四、数据流与状态

1. **扫描**：`os.scandir` 递归 → 忽略规则 → 魔数/扩展名识别 → 抽取正文 → 归一化 → 指纹 →
   写入 SQLite（`documents` / `fingerprints` / `pairs` 表）。缓存键见 `data/README.md` §四.8。
2. **召回**：SimHash 分桶缩小候选；MinHash/LSH banding 产生候选对；粗筛（大小窗口/扩展名）
   只减候选，不改变真值口径。
3. **聚类**：并查集合并候选对 → 每簇打分 → 三档分类 → 生成保留建议与理由字符串。
4. **复核**：Web 读取簇与 diff；用户勾选并显式确认后，POST 到隔离接口。
5. **执行**：先写 `manifest.json`（状态 `pending`）→ `shutil.move` → 更新为 `moved`；
   undo 按 manifest 逆序移回，移回前校验内容哈希。

## 五、确定性设计

| 关注点 | 做法 |
|---|---|
| 扫描结果 | 排序键 = 规范化绝对路径字符串（不依赖文件系统枚举顺序） |
| 指纹 | 固定 64-bit；shingle 固定 3-gram；归一化顺序固定（`data/README.md` §四.3） |
| 聚类编号 | 簇 id = 簇内最小规范化路径的 sha1 前 12 位（与遍历顺序无关） |
| 报告 | 无时间戳字段；JSON 用 `sort_keys=True, ensure_ascii=False, indent=2` + LF + 结尾换行 |
| 哈希 | 一律 `sha256`，十六进制小写 |
| 缓存键 | `sha256(规范化绝对路径|size|mtime_ns|抽取器版本|归一化版本|n-gram 参数)` |

**不得读取系统时钟**参与任何判定或产物内容；manifest 的时间字段由调用方显式传入（测试注入）。

## 六、安全与隐私

- Web 服务只绑定 `127.0.0.1`，**不监听 0.0.0.0**；无 CORS 开放、无遥测、无外部请求。
- 页面资源全部内联：无 `<link>`、无外链 `<script>`/`<img>`、无 `@import`、无外部字体。
  「零外链」作为渲染出口的**常驻断言**（生成 HTML 时即校验），不只在测试里验一次。
- 隔离区 `.dedupe-quarantine/`、索引库 `*.db`、导出报告一律进 `.gitignore`。
- 任何破坏性动作（隔离/撤销）都必须由用户在 Web 页面显式确认，或 CLI 显式加
  `--confirm`；默认路径**不动任何文件**。
- 相似度是机械测量值，界面与报告必须带免责声明：**不构成抄袭/侵权判断**。

## 七、测试与 CI

- 测试分层：`unit`（归一化/指纹/聚类/去重口径）、`integration`（扫描→报告全链路）、
  `cli`（退出码契约、失败路径）、`web`（TestClient 冒烟 + 零外链断言）。
- **退出码契约锁进测试**：0 正常完成 / 1 检出结果（如存在近重复簇）或门槛未达标 /
  2 用法或输入错误 / 3 依赖缺失或阶段未就绪。
- CI 矩阵：`windows-latest`、`ubuntu-latest` × Python 3.8、3.12；步骤：
  安装 `.[dev,web]` → 双入口冒烟（`python -m docdedupe --help` 与裸 `doc-dedupe --help`）
  → 全量 pytest → 生成器 `--check`（M1 起）。CI 环境变量 `PYTHONUTF8=1`。
- **本地等价校验**与 CI 分开记录：无远端时一律写"本地等价校验（未接远端，CI 待首推验证）"。
