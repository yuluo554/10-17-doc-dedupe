# 00 · README 总览 — 10-17-doc-dedupe（本地文档内容级去重与近重复整理器）

- 性质：不参赛项目题 · 发布 GitHub 公开仓库 · 署名 yuluo554
- 定位宣言："给本机文档做'正文级查重'——跨 PDF/Word/Markdown/TXT/HTML，找出'同一份内容的多个版本'，用可读的差异对比告诉你该留哪一份，并且只隔离、不删除。现有去重工具全部止步于哈希或图像；'文档正文相似'被 czkawka 以 P3-Large effort 关闭搁置——这正是小工具的窗口。中文无空格分词、页眉页脚污染、标书/论文/合同的模板族判定，是英文工具的结构性盲区。"
- 交付形态：**纯本地 Python CLI + 本地单页 Web 复核界面**（FastAPI + 原生 JS，无构建步骤）；无服务器、无 GPU、无网络。
- 下一棒：**M6（脱敏发布）**——读 `plan/HANDOFF-M6.md` 即可续接。

## 决策记录表

> 本表同时登记已定案决策与**弃选项**（含弃选理由），后续里程碑不再重复论证。

| 日期 | 决策 | 结论与理由 |
|---|---|---|
| 2026-10-17 | 形态定案：CLI + 本地单页 Web 复核（唯一形态） | 差异复核本质是视觉任务，纯终端表格难以胜任；单页 Web 无需构建链、无 CDN、零外部请求，仍是纯本地。不设备选形态，避免"任选其一"留空壳后门。 |
| 2026-10-17 | 弃"OCR 入首期" | OCR 会引入重模型依赖并显著扩大失败面，违背"纯本地轻量"；首期改为**显式 `skipped:no_text_layer`**，保证"不静默当不重复"。OCR 留作扩展项。 |
| 2026-10-17 | 弃"自动删除重复文件" | 近重复≠重复（同模板合同/发票/周报会成簇），误判代价不可逆。改为"隔离到 `.dedupe-quarantine/` + manifest + 一键撤销"，任何推荐都只是建议。 |
| 2026-10-17 | 弃"语义向量检索" | 需要 embedding 模型与向量库，违背纯本地轻量定位；字符 n-gram + SimHash/MinHash 已覆盖"同一内容的多个版本"这一核心场景。 |
| 2026-10-17 | 弃"自研 PDF 解析" | pypdf/pdfplumber 已成熟且月下载量级达数千万，自研仅增加失败面；首期只做文本层，不做版面重建。 |
| 2026-10-17 | 弃"词级 shingle（含 jieba 分词）" | 中文无空格，分词器版本与词典会引入不可控差异；**字符 3-gram** 无词典依赖、对改写更稳、口径可复现。 |
| 2026-10-17 | 模板族单列为独立档 | 同模板文档（合同/发票/周报）天然高相似，若与近重复混同会造成大规模误收；必须三档分离并由用户裁决。 |
| 2026-10-17 | 依赖分层：核心零依赖，`extract` / `web` / `dev` 三个 extras | M0 骨架必须能离线 `pip install -e .` 跑起来；PDF/DOCX 与 Web 栈按里程碑需要再装，缺 extras 时命令 exit 3 而非静默降级。 |
| 2026-10-17 | 下限 Python 3.8、CI 双解释器矩阵 | 本机 `py -0p` 实测只有 3.8.8 与 3.12；下限定 3.8 才能在本机跑通"用户会用的最老环境"，跨版本差异由 CI 矩阵覆盖。 |
| 2026-10-17 | 指纹自实现（SimHash + MinHash/LSH），不引 `simhash`/`datasketch` | 口径可单点控制、零第三方依赖、便于逐条单测；两者都只在本项目内部使用，不需要生态兼容。 |
| 2026-10-17 | 首期不做 exe 打包 | 交付形态是 CLI + 本地 Web，源码包 + editable 安装已足够；exe 会显著扩大发布面，留作扩展项。 |
| 2026-10-17 | 未实现命令一律 exit 3 并说明计划里程碑 | 骨架期最容易犯的错是让未实现命令返回 0 或空结果（"假绿"）；显式 exit 3 让 CI 与用户都能看出边界。该常量随模块落地逐项退役。 |
| 2026-10-17 | 弃"差异摘要的'差一页'"（首期） | 页级相似度要页边界，抽取层只给一条纯文本流、无版面坐标。缺定义就不编阈值：`diffing.py` 无页级分支、配置无页码阈值；每次基准运行打印该降级，测试断言摘要不含页级断言。补口径（页切分 + 页级阈值 + 页级真值样本）后才做，登记在 `plan/03` §六。 |
| 2026-10-17 | 复核页面不自动聚类（未 `report` 的索引只提示） | 自动聚类要么写库（页面成为写入方，违反模块④只读不变量），要么算而不写（页面与 `clusters` 表不一致，用户无从判断"报告说留 A、页面说留 B"）。选显式提示"先跑 report"，并有测试断言此时表仍为 0 行。 |
| 2026-10-17 | 复核页只读由 SQLite 层强制（`mode=ro`） | "模块④只读"若只写在文档里，一次误改就会静默写坏索引。改由 `store.connect_readonly` 以 `mode=ro` 打开，写入被 SQLite 直接拒绝；再加静态断言（AST 调用名）与运行时断言（把可写打开函数换成抛异常）各一条。 |
| 2026-10-17 | 隔离执行层不在 M4 抢跑 | 隔离涉及 manifest 状态机、中断恢复、sha256 校验（`plan/03` 模块⑤ 的完整验收），M4 只给按钮与 `confirm` 校验，接口显式返回 501 说明 M5 落地。宁可"明确未实现"，也不留一个未经验证的薄版本。 |
| 2026-10-17 | 隔离区位置 = 成员**共同父目录**下的 `.dedupe-quarantine/<batch-id>/` | 隔离产物留在语料旁边，"哪一份被收走"一眼可见；跨卷的簇（`os.path.commonpath` 抛错）直接拒绝并提示按目录分批，不做"猜一个地方放"的兜底。 |
| 2026-10-17 | 同批同名成员**确定性改名**（`方案__2.txt`），不覆盖 | 同一簇的成员常来自不同目录却同名（`A/方案.txt` 与 `B/方案.txt`）。覆盖会毁掉一份文件、事后无法判断丢了谁；按 `path_norm` 顺序取首个空名，续跑时算出同样的名字。 |
| 2026-10-17 | 批次登记表 `quarantine_batches` 只存 manifest 路径，不存第二份条目 | `undo --batch` 与页面都要"按 id 找到批次"，但没有根目录信息，表提供这层索引即可。若把 item 也存进库就有两份状态要同步，而"先写 manifest 再动文件"的全部价值就是磁盘上那份是唯一真相。 |
| 2026-10-17 | 只允许隔离**该簇成员**且**扫描后未改动**的文件 | 破坏性动作的对象必须就是用户复核过的那一份：路径先按 `clusters` 表校验成员身份，再比对 size/mtime 与索引——文件在扫描后被改过就拒绝并提示重新 `scan`。否则"页面看到的是 A、被收走的是改过的 A"无法察觉。 |
| 2026-10-17 | `--move` 空列表是用法错误，不是"全部" | 破坏性开关的语义必须写"动哪些"。空列表当通配符是最危险的默认值之一；`plan_batch` 直接拒绝，测试断言此时连 manifest 都不写。 |
| 2026-10-17 | undo 的"逆序复原"不作为注入项，改由测试记录调用序 | 对一组平坦文件，逆序与顺序在字节层面**不可观测**，拿它当注入就是假门。顺序由测试记录的 `move_file` 调用序断言；真正可证伪的三条注入是"少校验 sha256（改了字节也照恢复）""pending 项被跳过（假装成功却没搬）""copy 而非 move（同一份两份并存）"。 |
| 2026-10-17 | 页面按钮接通后，页脚文案同步改口径 | M4 的"本页只读展示"在 M5 之后不再成立：页面现在会移动文件。改成"索引只读打开；隔离只在点击确认后移动选中的文件，可随时复原"，保留"不联网、不上传文档内容"。文案与实际能力不一致本身就是一种假话。 |
