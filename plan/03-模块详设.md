### 模块① 扫描与格式适配层

**职责**：把目录树变成带正文的索引记录。

| 项 | 内容 |
|---|---|
| 输入 | `roots: list[Path]`、忽略规则（默认忽略 `.git`/`node_modules`/系统目录/`.dedupe-quarantine/`）、索引库路径 |
| 输出 | SQLite `documents` 表：`id / path_abs / path_norm / size / mtime_ns / ext / extract_status / text_sha256 / norm_sha256 / text / norm_text / cached_at` |
| 引擎 | `os.scandir` 递归；扩展名 + 魔数双识别；`pypdf`（PDF 文本层）/`python-docx`（段落+表格）/标准库（MD/HTML/TXT）；SQLite 缓存 |
| 入口 | `docdedupe scan <root...> [--db PATH] [--ignore PATTERN]...` |

**接口契约**

```python
# extract.py
class ExtractResult(NamedTuple):
    status: str      # "ok" | "skipped:no_text_layer" | "skipped:encrypted" | "skipped:unsupported"
    text: str
    extractor: str   # "pypdf@3" / "python-docx@1" / "text@1" / "html@1" / "markdown@1"

def extract(path: Path) -> ExtractResult: ...
```

**确定性纪律**

- 缓存键单点定义在 `store.cache_key()`，字段顺序与 `data/README.md` §四.8 逐字一致。
- 抽取失败**不得返回空字符串冒充成功**：无文本层 PDF → `skipped:no_text_layer`；
  加密 PDF → `skipped:encrypted`；未知格式 → `skipped:unsupported`。三者都**不入候选集**，
  但必须在报告与 `scan` 汇总里**显式计数并列出**。
- 一次扫描内遍历结果按 `path_norm` 升序处理（与文件系统枚举顺序解耦）。
- 同一输入两次扫描，`documents` 表内容（除 `cached_at`）逐字段一致。

**验收（M1）**

1. 1000 份混合格式（PDF/DOCX/MD/TXT/HTML）扫描不崩、无未捕获异常；
2. 二次扫描耗时相对首次下降 ≥ 80%（口径 `data/README.md` §四.9）；
3. 无文本层 PDF 与加密 PDF 在索引里分别落 `skipped:no_text_layer` / `skipped:encrypted`；
4. 缓存键任一字段变化即失效（改 mtime 后重扫必须重新抽取）。

### 模块② 中文友好指纹与召回

**职责**：把正文变成可比较的指纹，并产出候选相似对。

| 项 | 内容 |
|---|---|
| 输入 | 模块① 的 `norm_text` |
| 输出 | `fingerprints` 表：`doc_id / simhash / minhash_json / shingle_count / shingle_hashes`；`pairs` 表：`a_id / b_id / jaccard / jaccard_estimate / hamming / score_kind` |
| 引擎 | NFKC → 去空白/不可见字符 → 去页码行 → 去跨页高频短行（页眉页脚）→ 拉丁小写；字符 3-gram shingles；MinHash（128）+ LSH banding（32×4）**召回**候选对；候选对的 Jaccard 用已存 shingle 哈希**精确计算**；64-bit SimHash 只作预筛 |
| 入口 | `docdedupe scan` 内部调用（不单独暴露子命令，避免中间态被误用） |

**接口契约**

```python
# normalize.py
def normalize(text: str, settings: Settings | None = None) -> str: ...
NORMALIZE_VERSION = 1   # 归一化规则变更即递增，缓存键随之失效

# fingerprint.py
def shingles(text: str, n: int = 3) -> list[str]: ...
def shingle_hashes(text: str, n: int = 3) -> tuple[int, ...]: ...
def simhash64(shingle_list: Iterable[str]) -> int: ...
def minhash_signature(shingle_values: Iterable[str], num_perm: int) -> tuple[int, ...]: ...
def lsh_bands(sig: Sequence[int], bands: int) -> list[tuple[int, int]]: ...
def jaccard_from_signature(a, b) -> float: ...          # 估计值，辅助/审计
def jaccard_from_hashes(a, b) -> float: ...              # 精确值，落 pairs.jaccard
def build_candidates(entries, settings=...) -> tuple[list[Candidate], CandidateStats]: ...

# recall.py
def evaluate_recall(groups, edges, threshold, *, path_key=...) -> RecallReport: ...
```

**确定性纪律**

- **中文不得使用空格分词**；shingle 一律按字符切分（中英同一条实现路径）。
- 归一化顺序固定且只有一处实现；`NORMALIZE_VERSION` 变更须同步 `data/README.md`。
- 粗筛（归一化正文长度窗口 / SimHash 汉明）只能减少候选对，**不得进入真值口径**；真值按"应召回对"定义。
- **召回与判定分离**：MinHash/LSH 决定"哪些对进入打分"，精确 Jaccard 决定"分数是多少"。128 置换估计值的标准误（约 0.035）与本语料最弱真值对（0.81–0.83，仅高出阈值 0.01–0.03）同量级，用估计值判定等于让采样噪声决定分档。`pairs.score_kind` 记录判定所用口径，`jaccard_estimate` 留档对照。
- 第二次扫描在"指纹输入摘要 + `pairs` 结果摘要"都未变时跳过召回重算；两个摘要都落 `meta` 表，任一不符即重算（不是信任一个布尔标志）。

**验收（M2）**

1. 20 组人工构造样本（改写版 / 截断版 / 换格式版）召回率 ≥ 90%（判据 `data/README.md` §四.7），**逐组点名**；
2. 归一化用例集：全半角、跨页页眉、页码噪声、中英混排各至少一例，且同文不同格式归一后一致；
3. 同输入两次运行，`fingerprints` 与 `pairs` 逐字段一致；
4. `negative` 组零误报；缺陷注入后基准必须报未达标。

### 模块③ 聚类与保留建议

**职责**：把候选对合成簇，判定档位，给出人类可读的保留建议。

| 项 | 内容 |
|---|---|
| 输入 | `pairs`（分数 ≥ 近重复阈值） |
| 输出 | `clusters` 表：`cluster_id / member_ids / tier / keep_id / reason / scores_json` |
| 引擎 | 并查集；簇内打分（mtime 更新、路径更浅、文件名规范、元数据完整度、目录归属）；三档分类 |
| 入口 | `docdedupe report [--format md\|csv\|json] [--out PATH]` |

**三档定义**（判据细节见 `data/README.md` §四.5，此处只写语义）

| 档位 | 语义 | 处置 |
|---|---|---|
| 完全重复 | 归一化正文逐字节一致 | 建议保留 1 份 |
| 近重复 | 达到近重复阈值，且不属于模板族 | 建议保留 1 份，差异可复核 |
| 模板族 | 成员差异集中于字段位、存在同构骨架（合同/发票/周报） | **单列一档，永不建议批量处置** |

**接口契约**

```python
# cluster.py
@dataclass(frozen=True)
class Cluster:
    cluster_id: str
    members: tuple[str, ...]
    tier: str            # "exact" | "near" | "template"
    keep: str
    reason: str          # 非空、含至少两个判定维度
    scores: dict[str, dict[str, float]]

def build_clusters(docs, pairs, cfg) -> list[Cluster]: ...
```

**确定性纪律**

- 簇 id 与成员顺序由规范化路径排序派生，不依赖并查集遍历顺序。
- 打分公式**只在 `cluster.py` 一处实现**；报告层与 Web 层只能读取 `scores`，不得重算。
- 每簇 `reason` 必须非空且包含**具体判定维度**（如"修改时间最新""路径更浅""文件名无副本标记"），
  **禁止只输出裸分数**。
- 模板族必须单独成档，**不得与近重复混算**；模板族不产生"建议保留"（只提示人工裁决）。
- 程序**永不删除、永不自动处置**；本模块只产出建议。

**验收（M3）**

1. 每簇理由字符串非空且可被断言包含至少两个维度词；
2. 三档标签与合成真值完全一致；
3. 模板族样本不得出现在近重复档。

### 模块④ 差异复核界面

**职责**：让用户不碰命令行完成"看簇 → 看差异 → 决定保留 → 触发隔离"。

| 项 | 内容 |
|---|---|
| 输入 | 索引库（只读） |
| 输出 | 本地单页 Web：左侧簇列表（三档标签 + 推荐保留），右侧双栏差异高亮 + 摘要文案 |
| 引擎 | FastAPI 绑定 `127.0.0.1`；原生 HTML/CSS/JS（单文件、内联）；段落级 diff + 字符 n-gram 高亮 |
| 入口 | `docdedupe serve [--db PATH] [--port 8765] [--open]` |

**接口契约**

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 单页 HTML（内联全部资源） |
| GET | `/api/clusters` | 簇列表（含 tier / keep / reason / members） |
| GET | `/api/clusters/{id}/diff?a=&b=` | 段落级 diff 块 + 摘要 |
| POST | `/api/quarantine` | body：`{"cluster_id":..., "keep":..., "move":[...], "confirm": true}` |
| POST | `/api/undo` | body：`{"batch_id":..., "confirm": true}` |

`diff` 响应形状：

```json
{
  "cluster_id": "c1a2b3c4d5e6",
  "summary": "仅差 3 段",
  "left":  {"doc_id": "...", "path": "...", "segments": [{"kind": "same|add|del|replace", "text": "..."}]},
  "right": {"doc_id": "...", "path": "...", "segments": [...]}
}
```

**确定性纪律**

- 页面只读展示；任何写操作必须 `confirm: true` 且由用户在页面上点击确认。
- **零外链**：无 `<link>`、无外链 `<script>/<img>/<iframe>`、无 `@import`、无外部字体、无 CDN。
  该断言常驻在 HTML 生成出口（`web.server.render_page` 返回前校验），不是只在测试里验一次。
- 关闭 `/docs`、`/redoc`、`/openapi.json`（Swagger UI 会引 CDN）。
- 摘要文案由单一统计函数产出（`data/README.md` §四.10），页面不得自行拼口径。
- 页面不联网、不上传任何文档内容；服务只监听 `127.0.0.1`。

**验收（M4）**

1. 无命令行完成全流程复核（看簇 → 看差异 → 决定保留 → 触发隔离）；
2. 页面展示簇列表、三档标签、推荐理由、双栏差异高亮、差异摘要；
3. 断网可用；静态扫描断言零外链；
4. 无前端构建步骤（仓库无 `package.json`/`node_modules`/打包产物）。

### 模块⑤ 安全执行与回滚

**职责**：把"其余可收走"这件事做成**可逆**的隔离动作。

| 项 | 内容 |
|---|---|
| 输入 | 用户确认的簇与保留选择 |
| 输出 | `.dedupe-quarantine/<batch-id>/` 下的文件 + `manifest.json`；CSV/JSON 报告 |
| 引擎 | `shutil.move`；Windows 长路径 `\\?\` 前缀 + 句柄重试；manifest 状态机 `pending → moved`；逆序 undo；内容哈希校验 |
| 入口 | `docdedupe quarantine --cluster ID --keep PATH --move PATH... --confirm`、`docdedupe undo --batch ID --confirm`、`docdedupe reports --out DIR` |

**manifest 形状**

```json
{
  "batch_id": "20261017T101500Z-7f3a",
  "created_at": "2026-10-17T10:15:00Z",
  "cluster_id": "c1a2b3c4d5e6",
  "keep": "D:/docs/A/项目方案.docx",
  "items": [
    {
      "status": "moved",
      "original_path": "D:/docs/B/项目方案(1).docx",
      "quarantine_path": "D:/docs/.dedupe-quarantine/20261017T101500Z-7f3a/项目方案(1).docx",
      "sha256": "…",
      "size": 12345,
      "moved_at": "2026-10-17T10:15:01Z"
    }
  ]
}
```

**确定性纪律**

- **只隔离、不删除**；任何路径都不得调用 `os.remove`/`unlink`。
- **先写后动**：manifest 落盘（`pending`）后才执行移动，移动成功后改为 `moved`；
  进程中断后可从 manifest 恢复（`pending` 且文件仍在原路径 → 重做；文件已在隔离区 → 补齐状态）。
- undo 前校验 `sha256`，移回后必须与原路径**逐字节一致**；校验失败即中止并报告。
- 破坏性开关语义写"**动哪些**"而非"留哪些"（`--move` 显式列成员；不给 `--move` 时不做任何移动）。
- 隔离区与索引库**不入 git**（`.gitignore` 已锚定）。
- CSV/JSON 报告字段：`batch_id / cluster_id / tier / keep / moved_path / original_path / sha256 / status`。

**验收（M5）**

1. 撤销后文件路径与内容逐字节一致（sha256 比对）；
2. 扫描/移动中断后可从 manifest 恢复；
3. 报告字段完整可复核；
4. 无 `--confirm` 时任何破坏性命令 exit 2 且不触碰文件。

## 六、扩展项（首期不做）

| 扩展项 | 触发条件 | 不做理由 |
|---|---|---|
| PPTX/XLSX 正文抽取 | 首期五模块验收全绿后 | 增加依赖与格式失败面，先验证核心链路 |
| 语义向量检索 | 有明确需求与本地模型方案 | 违背纯本地轻量定位，字符 n-gram 已覆盖核心场景 |
| 目录增量监听 | 用户明确要求常驻进程 | 首期按需扫描已满足；监听会引入长驻进程与状态复杂度 |
| OCR（扫描件） | 用户接受重依赖 | 首期显式 `skipped:no_text_layer`，不静默 |
| 桌面 exe 打包 | 有非 Python 环境用户 | 首期源码包 + editable 安装足够 |

## 七、模块间不变量（跨模块锁死）

1. `documents.text` 与 `documents.norm_text` 只在模块①写入，其余模块只读。
2. `pairs` 只由模块②写入；模块③只读，不得改写分数。
3. `clusters` 只由模块③写入；模块④只读；模块⑤只读 `clusters` 并在 manifest 里快照当时值。
4. 任何模块都不得直接 `os.remove`；删除能力在代码层不存在。
5. 报告与页面展示的分数必须带 `score_kind`，不得把辅助信号当主分数。
