**关键设计取舍（写入 `data/README.md` §四.10 / `plan/03` 模块④）**：

2. **"差异仅来自版式或编码" 必须在计数之前判**：全半角 twins 的抽取文本真的不同（9 行），若直接计数会显示"仅差 18 段"，与同一索引给的 `exact` 档位自相矛盾。判定复用 `normalize`（§四.3 的唯一实现），不另立规则。
3. **未 `report` 的索引不自动聚类**：自动聚类要么写库（页面变成写入方，违反只读不变量），要么算而不写（页面与表不一致，回到"报告说留 A、页面说留 B"）。故选显式提示 + 测试断言此时表仍为空。
4. **Web 层零判定**：tier/keep/reason/scores 一律读 `clusters` 表（含 `scores_json`）；静态 AST 断言 `web/server.py` 不调用 `build_clusters`/`clusters_from_index`/`scores_json`/`shingle_set` 等，运行时再把 `store.connect` 换成抛异常跑一遍请求。
5. **字符级高亮在下发前算**：页面不得自己算高亮（否则是第二套口径）；`spans` 用已有的 3-gram 集合实现（`fingerprint.shingle_set`），逐字符判定"覆盖它的 n-gram 是否全部在对面缺失"。

**口径变更（DoD 文字）**：原 M4 DoD 写"无命令行完成…触发隔离全流程"，但隔离执行层是 M5 范围（`plan/03` 模块⑤、本节 M5 范围"Web 侧隔离与撤销接口接通"）。M4 交付的是复核 UI 与诚实占位的接口，不改 `plan/03` 的模块划分。
